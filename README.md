# Agent Kaggriculture

Agent intelligent consacré à l'analyse et à l'aide à la décision dans le domaine agricole.

## Objectif

Ce projet utilise l'intelligence artificielle pour analyser les demandes
de l'utilisateur et fournir des réponses utiles liées à l'agriculture.

## Fonctionnalités

- Analyse des demandes de l'utilisateur.
- Génération de réponses avec l'intelligence artificielle.
- Interface simple pour tester l'agent.
- Possibilité d'intégrer des données agricoles.

## Technologies

- Python
- Hugging Face
- Gradio
- GitHub

## Installation

```bash
git clone [https://github.com/adamasavadogoel12-coder/projet_agent_kaggri.git](https://github.com/adamasavadogoel12-coder/projet_agent_kaggri.git)
cd projet_agent_kaggri
pip install -r requirements.txt
```

## Utilisation

```bash
python app.py
```

## Sécurité

Ne publiez jamais vos clés API ou vos tokens dans ce dépôt.
Utilisez un fichier `.env` pour les informations confidentielles.
